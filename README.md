# Express E-Commerce API

E-commerce back-end built with Express, TypeScript and Prisma.

## Features

- JWT and Passport authentication with permissions
- Rate limiting and validation
- File uploads with Multer
- Prisma ORM

## Tech Stack

- TypeScript
- Prisma
- Express

## Getting Started

```bash
git clone https://github.com/ghostland-dev/express-ecommerce-api.git
cd express-ecommerce-api
cp .env.exemple .env   # then fill in your own values
npm install
npm run dev
```

Other scripts:

- `npm run build`: cp -rf ./src/views ./ build/ && tsc
- `npm run test`: echo \
